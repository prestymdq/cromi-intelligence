Widget demo · v0.1
Asistente para cualquier sistema

Tu conocimiento, en una conversación.

Esta es una demostración independiente. Tocá la burbuja para hablar con un asistente de preguntas frecuentes. Cambiá su apariencia sin tocar el motor.

Personalizá el chat

Estos cambios afectan solamente a la interfaz de demostración. En un proyecto real también podés configurar un avatar y conectar tus propias respuestas.

Preguntas configuradas

Para el ejemplo usamos información ficticia de una academia. No hay conexión a IA ni a servicios pagos.

«¿Cuáles son los horarios?»

«¿Qué cursos ofrecen?»

«¿Cómo me inscribo?»

Integración mínima

import { mountCromiWidget } from "./widget/cromi-widget.js";

mountCromiWidget({
  title: "Mi Asistente",
  accentColor: "#4f46e5",
  respond: ({ message, sessionId }) =>
    myEngine.respond(message, sessionId),
});
